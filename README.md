# Phrase Spinner

A classroom English slot machine for food and drink quantity phrases (for example, “Two boxes of potato chips”). The layout is a fixed 16:9 stage for electronic whiteboards.

課堂用英文短語拉霸：練習食物同飲品的數量說法。畫面係固定 16:9，方便電子白板使用。

Static single-page app. Open `index.html`, or view the Cloudflare Pages site after deploy.
